UPICuitous

A JUCE-based UPIC-inspired instrument for drawing pitch curves, playing samples, processing live audio, and synthesizing PM voices.

Standalone app, VST3 plugin, and Android APK. Direct release downloads are below.

Features

Score page

Draw pitch curves with magnetic sieves, grids, generators, multi-select, touch, and scrubbing.

Sample and PM

Varispeed, granular, phase vocoder, reverse playback, and phase-modulation voices.

Live input

Process microphone audio in realtime with granular, tape, and phase-vocoder modes.

Transport and IO

Play, loop, sequence pages, render WAV, save and load .upic.json.
